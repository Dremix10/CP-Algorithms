# CP-Algorithms

A library of algorithm and data structure implementations for competitive programming, built up over several years of contest prep (ICPC, IOI, BOI, Codeforces). Each file is a single self-contained, copy-paste-ready implementation — no external dependencies.

**Stack:** C++

## Organization

- **Data Structures** — Sparse Table, Fenwick Tree, Segment Tree (point/range update), Treap, DSU (including persistent and dynamic-connectivity variants), Trie
- **Graph Algorithms** — traversal (BFS/DFS, cycle detection), minimum spanning trees (Kruskal, Prim), shortest paths (Dijkstra, Floyd-Warshall), tree queries (LCA, kth ancestor, subtree/path queries), tree algorithms (diameter, subtree size), directed graph algorithms (topological sort, longest path)
- **String Algorithms** — KMP, Z-algorithm, string hashing, substring hash comparison
- **Geometry** — point-on-segment tests
- **Utility** — custom hash functions, coordinate compression

## Usage

Each `.cpp` file is standalone — copy the one you need directly into a contest submission. No build system required.
